Scratch scripts that produced the published 2025 preliminary release layout-001 on 2026-11-22. They were run from a session scratch folder with that folder as the project root, plus hand edits, so layout-001 is not reproducible from the repositories. Kept here as reference only; layout-002 must be built from committed builders with no hand edits. Paths inside these scripts refer to the original session scratch folder.
