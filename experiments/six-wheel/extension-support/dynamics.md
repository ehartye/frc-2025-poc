## Reproduce and use the surface

Use the project environment with NumPy, OpenCascade and the existing camera packages for the legacy registered navigation producer. The raw matching navigation file is generated by the original relieved-match replay. Use an independent output directory. The following commands run from the project root.

```text
python extension-support/dynamics_motion.py <relieved-match-raw> <output>/motion.json
python extension-support/dynamics_receipt.py <output> --run-cases
python extension-support/dynamics_witness.py <output>/leftSmall-nominal-62.5us.npz <output>/leftSmall-nominal-62.5us.json <output>/witness.json
python extension-support/dynamics_receipt.py <output> <output>/review.json
python -m unittest discover -s tests -p test_extension_dynamics.py
```

The issued report checks the registered motion and witness files alongside its traces. A new source configuration needs its own registration. A single case can accept an independently pinned complete terminal state containing `p`, `a`, `z` and `zdot`, with positions in metres and the issued stowed modal order. Supply `--state FILE --state-sha256 HEX`. The `legacy` variant applies the projected structural disturbance. For a recorded outbound stroke, supply `--motion FILE --motion-sha256 HEX` with columns `time_s,stroke_m,velocity_mps,acceleration_mps2` starting from zero stroke. Each interval uses a cubic position matching both endpoint positions and velocities. Its two implied endpoint accelerations must each agree with the supplied acceleration to 0.1 m/s² plus 2% of the supplied magnitude. The check also rejects an interior reversal. The receipt reports the supplied final timestamp as its duration and the last completed solver tick separately.

```text
python extension-support/dynamics_run.py <output> --case leftSmall --dt-us 31.25 --variant nominal --sample-us 31.25
python extension-support/dynamics_surface.py <trace.npz> <trace-sha256> <elapsed-seconds> <local-x-metres> <local-y-metres>
```

The sampler returns Z displacement relative to the original horizontal surface, material vertical speed, both local slopes and chassis X. The original top plane is Z500 mm. Add the local feature height for any recessed pad. Published comparison traces save every millisecond with endpoint velocities. Use every solver step for release/contact replay. The trace's geometric surface can still be queried after a guard fails; consuming it does not authorize a new action. A capable continuation needs a two-way pipe contact model, actual stroke tracking and an independent check of the changed camera and field geometry.
