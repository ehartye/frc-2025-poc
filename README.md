The current design is the preliminary whole-robot layout shown above. No detailed design is current: the earlier rough-draft showcase model is withdrawn, and the [detailed design status page](https://ehartye.github.io/frc-2025-poc/detailed-design/) gives the reason. Its pages left the site; Git keeps them, with the README that described that draft, at commit [`33a2315`](https://github.com/ehartye/frc-2025-poc/tree/33a2315).
